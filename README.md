
# 🥃 Ginshot

**Ginshot** is a command-line tool designed to generate a structured boilerplate for building APIs and microservices with the [Gin](https://github.com/gin-gonic/gin) framework.  
It helps developers scaffold routes, layered architecture files, and essential configurations to accelerate project setup and ensure best practices.  

---

## 🛠 Installation

Install `ginshot` using the following command:

```bash
go install github.com/mates182/ginshot@latest
```

Once installed, verify the installation:

```bash
ginshot -h
```

Alternatively, build manually from the source:

```bash
git clone https://github.com/mates182/ginshot.git
cd ginshot
go build -o ginshot .
```

---

## 📖 Usage

Run the following command to see available options:

```bash
ginshot -h
```

### ⚙ Available Commands

#### 1. 🏗 `init` - Initialize a new Gin project

```bash
ginshot init
```

**Description:**  
Sets up a new Gin project with a standard folder structure, configuration files, and optional Docker support.

**Example:**

```bash
ginshot init my-project -p 8080
```

---

#### 2. 🏃‍♂️ `serve` - Build and run the project using Docker Compose

```bash
ginshot serve
```

**Description:**  
Builds and runs the project using `docker-compose up --build -d`.  
Ensures that all services defined in the `docker-compose.yml` file are running.
Docker must be running to run the command.

**Example:**

```bash
ginshot serve
```

---

#### 3. 🏗 `brew` - Generate scaffold files from templates or JSON

```bash
ginshot brew [filename]
```

**Description:**  
Generates `models`, `requests`, and `responses` based on the provided JSON file.  
If no filename is specified, it lists available template files and prompts the user to generate a new one if none exist.

**Example:**

```bash
ginshot brew template.json
```

---

#### 4. ⚡ `mix` - Generate controller, service, and route files

```bash
ginshot mix
```

**Description:**  
Prompts the user to specify request and response types, then creates the necessary controller, service, and route files.

**Example:**

```bash
ginshot mix
```

---

#### 5. 🐚 `completion` - Shell autocompletion script

```bash
ginshot completion [shell]
```

**Description:**  
Generates shell completion scripts for `bash`, `zsh`, `fish`, and `powershell`.

**Example:**

```bash
ginshot completion bash
```

---

#### 5. ℹ️ `help` - Display help information

```bash
ginshot help
```

**Description:**  
Shows a list of available commands or detailed help for a specific command.

**Example:**

```bash
ginshot help brew
```

## 📂 Project Structure

A typical project generated by `ginshot` follows this structure:

```
my-project/
│-- brewer/
│-- config/
│   └-- cors/
│-- controller/
│-- models/
│-- data/
│   ├-- requests/
│   └-- responses/
│-- router/
│-- service/
│-- main.go
│-- Dockerfile
│-- docker-compose.yml
│-- ginshot.json
│-- .gitignore
│-- README.md
```

---

## ⚙ Configuration

The `ginshot.json` file allows you to configure project settings, for example:

```json
{
  "project_name": "my-project",
  "port": "8080",
  "cors": true,
  "dockerfile": true,
  "docker_compose": true,
  "gitignore": true
}
```
